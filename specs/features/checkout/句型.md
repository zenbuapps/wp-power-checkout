# checkout domain 句型模型

> Phase 03 BDD Analysis（Phase 2）。Boundary = web-backend。本 domain 句型為 single flat list。
> 共用句型（與 settings domain 共用）：G1「結帳強化設定 "<key>" 為 "<value>"」/ G2「結帳強化設定為：」— 定義於此，settings/句型.md 引用。

## QA 五維分析

| 維度 | 分析 |
|------|------|
| 等價類 | 開關 yes/no；國家 TW/非 TW/空；購物車 全虛擬/混合/可下載實體/空；電話 合法手機/市話/位數不足/國碼；requires 五值 |
| 邊界值 | 差額 = 0（小計 1000）、> 0、< 0；電話 9 碼 / 10 碼；千分位 1,250 |
| 狀態轉換 | 等待付款→處理中（自動→已完成）、保留→處理中、等待付款→保留（不觸發） |
| 錯誤/例外 | 驗證失敗訊息；自動完成拋例外仍不中斷回呼；商品已刪除 |
| 安全 | 文案 XSS 跳脫；電話不改寫原值 |
