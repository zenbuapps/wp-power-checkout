## 句型清單

### Given

| ID | 句型 | Handler |
|----|------|---------|
| S-G1 | `管理員已登入並取得 Nonce` | 建立 administrator + wp_create_nonce('wp_rest') |
| S-G2 | `目前身分為 "<訪客/一般顧客>"` | wp_set_current_user(0 / customer) |
| S-G3 | `wp_options 中不存在 "<option>"` | delete_option |
| S-G4 | `woocommerce_checkout_enhancement_settings 為：` + table(key, value) / `… 的 "<key>" 為 "<value>"` | update_option |

### When

| ID | 句型 | 操作 |
|----|------|------|
| S-W1 | `[管理員]發送 <GET/POST> /wp-json/power-checkout/v1/settings/checkout_enhancement[：` + table(key, value)`]` | O1 / O2（rest_do_request） |

### Then

| ID | 句型 | 類型 |
|----|------|------|
| S-T1 | `回應狀態碼為 <n>` | Result |
| S-T2 | `回應 message 為 "<msg>"` | Result |
| S-T3 | `回應 data 應為：` + table(key, value) | Result |
| S-T4 | `woocommerce_checkout_enhancement_settings 應包含：` + table / `… 的 "<key>" 應為 "<value>"` | State |

## QA 五維分析

| 維度 | 分析 |
|------|------|
| 等價類 | 身分：管理員 / 訪客 / 一般顧客；值：合法 / 不合法 |
| 邊界值 | 色碼 #fff（3 碼）不合法；文案缺 {price} |
| 狀態轉換 | 未儲存 → 預設；部分更新 → 合併 |
| 錯誤/例外 | 401 / 403；不合法鍵忽略（仍 200） |
| 安全 | 權限、nonce、`<script>` 移除 |
