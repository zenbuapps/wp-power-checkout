# 系統抽象

> Phase 03 BDD Analysis（Phase 1）產出。建立於 2026-11-13，**本次 scope 僅涵蓋結帳體驗強化（checkout + settings/checkout-enhancement）**；
> 既有 payment / invoice / logistics / settings 其他 feature 尚未納入本文件，日後擴充時以 reconciler 增量補上。
> Boundary：`web-backend`（`specs/erm.dbml` 存在）—— WordPress + WooCommerce 後端，測試以 `tests/Integration/`（WP_UnitTestCase）驅動。

## 1. 對外操作

| # | 操作 | 觸發者 | 入口 | feature |
|---|------|--------|------|---------|
| O1 | 讀取結帳強化設定 | 管理員 | `GET /power-checkout/v1/settings/checkout_enhancement` | settings/checkout-enhancement-settings |
| O2 | 儲存結帳強化設定 | 管理員 | `POST /power-checkout/v1/settings/checkout_enhancement` | settings/checkout-enhancement-settings |
| O3 | 開啟結帳頁（取得地址欄位定義） | 顧客 | 傳統：`WC()->checkout()->get_checkout_fields()`；區塊：`WC()->countries->get_country_locale()` + `woocommerce_states` | checkout/checkout-address-fields |
| O4 | 送出訂單 | 顧客 | 傳統：`WC_Checkout::process_checkout` 驗證（`woocommerce_after_checkout_validation`）；區塊：Store API `POST /wc/store/v1/checkout` | checkout/checkout-field-validation |
| O5 | 訂單轉為處理中 | 第三方金流 / 管理員 | `$order->payment_complete()` / `$order->update_status('processing')` | checkout/virtual-order-auto-complete |
| O6 | 開啟購物車 / 結帳頁（取得免運提示） | 顧客 | 傳統：hook 輸出 HTML；區塊：Store API `GET /wc/store/v1/cart` extensions | checkout/free-shipping-hint |

## 1b. 系統前置狀態部件

| 部件 | 注入方式（States Prepare） |
|------|---------------------------|
| 結帳強化設定 | `update_option('woocommerce_checkout_enhancement_settings', [...])` |
| 商店基本國家 / 小數位 / 含稅顯示 | `update_option('woocommerce_default_country' / 'woocommerce_price_num_decimals' / 'woocommerce_tax_display_cart')` |
| 商品（虛擬 / 可下載） | `WC_Product_Simple` + `set_virtual()` / `set_downloadable()` |
| 購物車 | `WC()->cart->add_to_cart()`、`apply_coupon()` |
| 運送區域與運送方式 | `WC_Shipping_Zone::add_shipping_method()` + `woocommerce_{method}_{instance}_settings` |
| 訂單 | `wc_create_order()` + `add_product()` + `set_status()` |
| 發票 provider | `woocommerce_amego_settings`（enabled + auto_issue_order_statuses）+ API_MODE=mock |

## 2. 實體

| 實體 | 類型 | 說明 |
|------|------|------|
| CheckoutEnhancementSettings | Aggregate（wp_options） | 見 erm.dbml `wp_options_checkout_enhancement_settings` |
| Cart | WC Aggregate（外部） | 品項虛擬性、小計、折扣、套用的優惠券 |
| Order | WC Aggregate（外部） | 狀態、品項、order note |
| ShippingZone / free_shipping method | WC 設定（外部，唯讀） | min_amount / requires / ignore_discounts |
| TwAdminDivision | 程式內常數 | 22 縣市 → 鄉鎮 → 郵遞區號 |

## 3. 操作分類

| 分類 | 操作 |
|------|------|
| Mutation | O2（設定）、O5（訂單狀態） |
| Query | O1、O3、O6 |
| Validation-Command（成功即建立訂單，失敗回錯誤） | O4 |

## 4. 共用契約

- **開關閘門**：所有 checkout 操作先讀 `CheckoutEnhancementSettings` 對應開關，`no` 時行為與 WooCommerce 原生完全相同（零副作用）。
- **TW 判定**：運送國家 → 帳單國家 → 商店基本國家，依序取第一個非空值。
- **全虛擬判定**：品項數 ≥ 1 且每一品項的商品存在且 `is_virtual()`。
- **never-throw**：O3/O4/O5/O6 的 hook callback 任何 `\Throwable` 皆攔截並 `Plugin::logger()`，不中斷 WC 流程（O4 的驗證失敗是預期的錯誤回應，不算例外）。
- **跳脫**：所有輸出至前台的文案、色碼皆經 `esc_html` / `esc_attr`。
- **結帳型態雙軌**：每個前台操作需分別驗證「傳統」與「區塊」路徑（支援矩陣見 `specs/open-issue/checkout-enhancement-execution-plan.md`）。

## 5. 變異點

| domain | 特有行為 |
|--------|---------|
| settings | 鍵級驗證（yes/no、#RRGGBB、{price}）不合法鍵忽略而非整包拒絕 |
| checkout / 地址 | 區塊結帳無鄉鎮下拉；虛擬判定只在頁面載入時 |
| checkout / 驗證 | 區塊結帳錯誤回 HTTP 400（Store API），訊息不含 `<strong>` |
| checkout / 自動完成 | 任何轉 processing 皆觸發（含管理員手動） |
| checkout / 免運 | 門檻僅讀 WC 內建 free_shipping；區塊經 Store API extension |
