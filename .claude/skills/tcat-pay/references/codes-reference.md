## 4. 收單行 / 繳款方式 / 銀行代碼

**CVS（超商銀行繳款）送單**
- `payment_type`：`0` ibon 繳款／`1` ATM 銀行轉帳。
- `payment_acquirerType`（收單行）：`2` 安源（ibon 超商，上限 20,000）／`3` 統一金流（ATM 虛擬帳號，上限 49,999）。
- `bank_id`（統一金流 ATM 指定繳費銀行）：`822` 中國信託／`013` 國泰世華（可留空隨機/由消費者選）。回覆 `bank_id` 為 3 碼銀行代號（範例另見 `808` 玉山商銀）。
- `ibon_shopid`（廠商代碼）：`CCAT`、`BCAT`。

**CVS 回覆 `cvs_acquirer_type`**（⚠️ 值域不一致）
- 訂單查詢定義：`2` 安源／`3` 統一金流。
- CvsIbonUpdateDate 回覆定義：`0` 玉山／`1` 中信／`2` ibon(安源)（**舊制殘留**；玉山、中信已於 1.23、1.22.1 移除為 CVS 收單行）。
- 判斷收單行請以送單的 `payment_acquirerType` 為準。

**COCS（線上刷卡）`acquirer_type`**
- 送單值：`esun` 玉山銀行／`chinatrust` 中國信託／`payuni` 統一金流。
- CocsOrderQuery 回覆值：中文行名「玉山銀行」「中國信託」「統一金流」（非送單的英文代碼）。

## 5. 金額上限

| 收款方式 | 上限（TWD）|
|---------|------|
| CVS 安源 ibon 超商繳款 | 20,000 |
| CVS 統一金流 ATM 虛擬帳號 | 49,999 |
| COCS 線上刷卡 `order_amount` | 依合約，預設 100,000 |
| 續期收款 `period_amount` / `first_amount` | 依合約，預設 100~100,000 |

`order_amount` / `cr_amount` / `refund_amount` / `period_amount` 皆為整數數值，不可有小數位。

## 6. 電子發票欄位值域

- `b2c`：`0` 不開立（預設）／`1` 開立。
- `print_invoice`：`0` 不列印／`1` 列印。
- `vehicle_type`（載具類別）：`1` 會員（發票平台）載具／`2` 手機條碼／`3` 自然人憑證。
- `donate_invoice`：`0` 不捐贈／`1` 捐贈；`love_code` 捐贈時填，留空預設創世基金會 `919`。
- 規則：捐贈發票、統編(公司戶)發票、印製紙本發票、共通載具「只能選一種」。
- 完整欄位定義見 `api-reference.md §5`。
