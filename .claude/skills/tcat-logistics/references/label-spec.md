# 託運單版面規格（A4 二模 / A4 三模 / 熱轉印 / 撿貨單）

來源：官方「黑貓A4-2模託運單規格說明.xls」「黑貓A4-2模託運單規格說明_new.xls」「黑貓A4-3模託運單規格說明.xls」「黑貓熱轉印託運單規格說明.xlsx」，以及六份託運單樣張 PDF。

> **重要定位**：使用印單 API 的 `PrintType='01'`（速達標準版型）時，**PDF 由速達產生**，你只需 `DownloadOBT` 拿檔案列印——**不需要自繪標籤**。本檔的用途是：(a) 確認印表機 / 紙張 / 標籤貼紙的實體規格是否相容；(b) 版面驗收；(c) 少數需自行套印或設計出貨作業流程時的參考。

## 5. 條碼規格

> ⚠️ **官方文件未明列條碼符號體系（symbology）、寬度、密度、粗細比**。以下為**樣張 PDF 實測**萃取，符號體系依人眼可讀文字中的 `*` start/stop 字元**研判為 Code 39**。若需精確條碼參數（模組寬度、quiet zone），請向統一速達營業系統窗口索取。

### 5.1 宅配單上的條碼

| 條碼 | 人眼可讀文字 | 內容 | 說明 |
|---|---|---|---|
| **託運單號條碼** | `*140002374983*` | 12 碼數字 | `*` 為 Code 39 start/stop。內容 = `OBTNumber`（API 回傳值）|
| 託運單號（文字）| `1400-0237-4983` | — | **顯示格式為 4-4-4 分組**，加連字號。同時標示為「包裹查詢號碼」|
| **郵號條碼** | `*+1211406*` | `+` + 7 碼數字 | 內容為 `+` 前綴 + 郵號數字部（不含理貨碼字母）|
| 郵號（文字）| `12-114-06-S` | — | 完整郵號含理貨碼字母。**API `SenderZipCode` 要的六碼 = `11406S`**（見 `api-reference.md` §1.4）|
| **代收貨款條碼** | `*000000000000*` | 12 碼數字 | 不收款時為 12 個 `0` |
| 版本標記 | `API1.0.0` | — | 樣張上印有 API 版本字樣 |

```

寄件人      金財通 / 02-87121298 / 0987654321 / 11406 台北市內湖區民權東路六段21巷69號
收件人      黑貓探險隊 / 02-87654321 / 0912345678 / 台北市重陽路200號
訂單編號    SN202012010001
品名        一般食品 澎湖-XO干貝醬        ← 商品類別 + 商品名稱併印
備註        易碎品，請小心平放
代收        不收款
收貨日      2020-12-01     希望配達日 2020-12-02    希望配達時段 13時前
尺寸        60cm           溫層 常溫
郵號        12-114-06-S    條碼 *+1211406*

> **品名欄印的是「商品類別中文 + 商品名稱」併排**（`一般食品澎湖-XO干貝醬`），亦即 `ProductTypeId` 會被轉成中文一起印出。設計 `ProductName` 內容時要考慮這個併印寬度。

### 5.2 7-11 快速到店（B2S）單上的條碼

B2S 單多出「門市驗收 / 取件聯」，條碼較多：

| 條碼（樣張實測）| 長度 | 研判組成 |
|---|---|---|
| `*8611317H77H729469574*` | 20 | 門市店號(6) + 廠商編號(3) + 廠商編號(3) + 配送編號(8) |
| `*0912167H7*` | 9 | *(不確定)* + 廠商編號(3) |
| `*2946957430000082*` | 16 | 配送編號(8) + *(8 碼不確定)* |
| `*930005203251*` | 12 | 託運單號 `OBTNumber` |
| `*000000000000*` | 12 | 代收貨款（不收款）|

> ⚠️ **上表「研判組成」為對照樣張其他欄位（廠商編號 `7H7-7H7`、配送編號 `29469574`、門市店號 `861131`、託運單號 `930005203251`）推得，官方文件無條碼組成規格。** 不可據此自行產生條碼——請一律使用 `DownloadOBT` 回傳的官方 PDF。

**B2S 單樣張欄位**：

```
快速到店-門市驗收/取件聯
GOT 驗收條碼
廠商編號: 7H7-7H7          配送編號: 29469574        ← 對應 API 回傳的 DeliveryId
預計退貨日: 2020/12/09
託運單號: 930005203251     ← 對應 API 回傳的 OBTNumber
門市: 861131 綠洲          ← 對應 request 的 ReceiveStoreId
請檢視證件                 常溫 宅急便快速到店
手機末三碼 321             不需電聯收件人/快速到店
FB名稱: FB1234             ← 對應 request 的 FBName
收件地址: 23722新北市三峽區鳶山里12鄰中山路186號1樓   ← 門市地址（非收件人地址）
寄件人: 黑貓探險隊  收件地址: 11534L台北市重陽路200號 / 02-87654321 / 0912345678
希望配達日 12月2日   尺寸: 60cm   溫層: 常溫

> **「預計退貨日」= 出貨日 + 7 天**（樣張：2020/12/02 配達、2020/12/09 預計退貨）。這是 7-11 到店取貨的**保留期限**，超過未取即退回。API request 中**沒有這個欄位**，由速達自動計算。
> **「手機末三碼」印在單上**供門市核對取件人身分——這是 `RecipientMobile` 必填且必須為 `09` 開頭的原因。

## 6. 撿貨單（A4 三模揀貨單）

樣張 PDF 為 6 頁。無獨立尺寸規格書，版面沿用 A4 三模。實測欄位：

```
託運單號: (含條碼 *140002375183*，顯示「包裹查詢號碼：1400-0237-5183」)
頁次:                      ← 撿貨單有分頁
姓名:
寄件人 / 收件人 區塊
收貨日 / 希望配達日 / 希望配達時段 / 發貨所 / 尺寸
訂單編號 / 品名 / 備註
代收貨款 / 收件人簽名
```

> 撿貨明細表的**自訂欄位標題（`Detail.Title.Column01~04`，各 5 字）與內容（`Body[].Column01~04`，各 20 字）**、**頁尾四行（`Footer.Row01~04`，各 50 字）**會印在此版型上。字數上限即為版面容納上限，超過會被截斷。

## 7. 實作檢核清單

- [ ] 使用 `PrintType='01'` 時**不需自繪標籤**，直接列印 `DownloadOBT` 回傳的 PDF。
- [ ] 列印時**不可縮放**（fit-to-page 會破壞條碼密度與貼紙對位）。務必設定「實際大小 / 100%」。
- [ ] 熱轉印版型寬度固定 **9.45 cm**，採購標籤紙需符合；黏貼聯高 7.3 cm、配送聯高 12.0 cm。
- [ ] A4 二模的四聯尺寸不同（8.3×7.15 / 8.3×12.0 / 6.5×12.0 / 6.5×7.15），裁切線位置要對。
- [ ] `ProductName`（20 字）會與商品類別中文**併印在同一格**，實際可視寬度小於 20 字。
- [ ] B2S 單的「收件地址」印的是**門市地址**，不是收件人地址（B2S request 本來就沒有 `RecipientAddress`）。
- [ ] 兩份 A4 二模規格書以 `_new` 為準（會計聯 6.4→6.5 cm、尺寸欄位換列）。
- [ ] 條碼參數（密度 / 粗細比 / quiet zone）**官方未提供**——若需自行套印務必先向速達索取，不要憑樣張反推。
